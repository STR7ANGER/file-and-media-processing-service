# File and Media Processing Service

Tenant-safe, resumable media ingestion using Next.js, Hono, Go, PostgreSQL/Prisma, Redis, MongoDB, and S3-compatible object storage.

```bash
cp .env.example .env
docker compose up -d
npm install
npm run db:generate
npm run check
npm run build
```

The current slice safely finishes at quarantine and a versioned scan event. Malware scanning and safe promotion are designed for tasks 11–12; no quarantined object is deliverable.
